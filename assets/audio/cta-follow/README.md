# Stem CTA Follow

- `follow-full.wav`: audio final CTA Azrul sepanjang 5,941 detik, berisi narasi Bambang, musik, dan SFX. Pakai hanya bila teks CTA sama.
- `follow-voice.wav`: narasi CTA dengan posisi waktu asal, termasuk jeda awal.
- `follow-music.wav`: musik hangat CTA dari stem proyek Azrul.
- `follow-ui.wav`: jalur SFX tombol dan ikon dari stem proyek Azrul.

Keempat file 48 kHz stereo dan berawal pada titik yang sama. `follow-full.wav` berasal dari master final, sedangkan stem lainnya berasal dari mix sebelum master; setel level akhir saat menggabungkan stem. Waktu visual dan SFX ada di `../../animation/cta-follow/timing.json`.
