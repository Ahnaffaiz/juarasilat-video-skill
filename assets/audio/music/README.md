# Musik reusable

`bed-teknik-dm-loop-16s.wav` adalah alas musik D minor 16 detik yang dapat diulang tanpa jeda, 48 kHz stereo. Gunakan pelan di bawah narasi bedah teknik; sesuaikan level dan ducking dengan suara pada tiap film.

`generate.py` membangun ulang file dari nada sintetis, tanpa footage atau sampel pertandingan tertentu. Musik CTA hangat berada di `../cta-follow/follow-music.wav`.
